# Agent notes

Luca created Ingoizer's World and has the final say on story, characters, and what ships.

## Changelog

Every pull request adds an entry to `CHANGELOG.md` before it merges. The in-game What's New panel fetches that file, so the entry is what players read.

- Put the new entry first, under the current version heading, or under a new `## v0.x — Title` when it is a new milestone.
- Date it in Pacific time.
- Link the pull request as `[#123](https://github.com/genemagg10/adventure-game/pull/123)`.
- Write one or two sentences, in plain language, about what changed for a player.
- Do not name the sealed fight's weapon, or the three named keys. The Hall's public names are enough.
